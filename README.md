# FreshKeeper 🍎

[**中文文档**](./docs/README.md)

FreshKeeper is a simple and effective tool designed to help you keep track of expiration dates and the state of your household items before it's too late.

Whether it's food, medicine, skincare, baby products, pet supplies, or any other household essentials, FreshKeeper helps you manage them all in one place. Add items manually, or create them quickly from photos, and set reminders before they expire so you don't discover they've gone bad when you need them.

---

## Why FreshKeeper?

FreshKeeper is built for everyday home use. Whether you want to avoid forgotten ingredients in the fridge, expired medications, or skincare products that have been open too long, it helps you stay organized and reduce waste simply and effortlessly.

---

## Key Features

- **Track Expirations**: Keep track of the expiration dates of food, medicines, skincare, and daily necessities.
- **Easy Entry**: Add items manually or create them instantly from photos.
- **Visual Reference**: Save packaging photos for easy review later.
- **Organize**: Use categories and tags to sort and manage your items.
- **Reminders**: Set customized reminders before items expire.
- **Quick Search**: Search items by name, tags, or categories.
- **Archive**: Archive old items while keeping their history for future reference.
- **iCloud Sync**: Sync data across multiple devices via iCloud.

---

## Stay Ahead of Expirations

FreshKeeper helps you clearly understand what's still fresh, what's expiring soon, and what needs immediate attention. Instead of waiting until it's too late, plan ahead and use your items in time.

---

## Faster Item Entry

Our photo-based entry system makes recording item details and keeping visual references a breeze. For items you buy frequently and need to check later, this provides a much more practical management experience.

## Development

This project is built with [React Native](https://reactnative.dev/) and [Expo](https://expo.dev/).

### Prerequisites

- Node.js
- npm/yarn/pnpm

### Setup

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npm start
   ```

3. Run on your device/emulator:
   - Press `a` for Android
   - Press `i` for iOS
   - Press `w` for Web
